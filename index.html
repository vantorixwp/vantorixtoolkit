What Pro adds

Five modules. Each one switches on from the Modules screen you already use.

Archive Builder

Design one template and point it at the archives you choose — a post type, a category, a tag, an author, or everything. Targeting rules decide where it applies, so a shop archive and a blog archive can look nothing alike.

Single Post Builder

Lay out single posts, pages and custom post types in Elementor. Include or exclude by post type, by term, or by individual post, with a priority order when more than one template could match.

Search Builder

Replace the theme's search results page with one you build. Preview it against a real search term while you work, so you are not designing against an empty screen.

Dynamic Tags

Over 40 tags that pull real content into any Elementor field: post title, excerpt, featured image, author details, taxonomy terms, custom fields and ACF values, plus site and archive data.

Template Library

Import ready-made headers, footers, archives and single layouts in one click, or bring in a whole kit with its global styles. Save your own layouts back to the library and reuse them on the next project.

Download and install

The Pro plugin is free to download. It installs quietly and stays dormant until a licence is applied, so you can put it in place before you buy.

Download vantorix-pro.zip Get the free plugin

Requires the free Vantorix Toolkit 1.1.0 or newer, WordPress 6.0+, and Elementor.

  1. Install the free plugin first

    Search for “Vantorix” under Plugins → Add New, or install it from WordPress.org.

  2. Upload the Pro zip

    Plugins → Add New → Upload Plugin, choose vantorix-pro.zip, then activate.

  3. Apply your licence

    Go to Vantorix → License, paste the key we send you, and press Activate.

  4. Switch the modules on

    Vantorix → Modules. The five Pro modules are now yours to enable one at a time.
