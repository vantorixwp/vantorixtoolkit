Documentation

Everything about installing, licensing and building with Vantorix. If something here is wrong or missing, tell us and it gets fixed.

Requirements

WordPress6.0 or newer
PHP7.4 or newer
Elementor3.5 or newer (the free version is enough)
Vantorix Toolkit1.1.0 or newer, required by Pro

Elementor Pro is not required. Vantorix works alongside it if you already have it.

Install the free plugin

  1. In your dashboard, go to Plugins → Add New.
  2. Search for Vantorix.
  3. Press Install Now, then Activate.
  4. A Vantorix item appears in the admin menu.

You can also download the zip from WordPress.org and upload it under Plugins → Add New → Upload Plugin.

Install Pro

Pro is a second plugin that sits on top of the free one. Install the free plugin first, or Pro will tell you it cannot start.

  1. Download vantorix-pro.zip using your licence key.
  2. Go to Plugins → Add New → Upload Plugin and choose the file.
  3. Press Install Now, then Activate.
  4. A License item appears under the Vantorix menu.

The download needs your licence key. Once installed, Pro stays dormant until the key is applied on that site — nothing changes and nothing breaks in the meantime.

Apply a license

Licenses are issued by hand. Send us the domain you want to use and we send a key back, usually the same day.

  1. Go to Vantorix → License.
  2. Paste your key, or your ThemeForest purchase code, into the field.
  3. Press Activate.
  4. Go to Vantorix → Modules and switch on the modules you want.

How domains are counted

  • example.com and www.example.com count as one site.
  • Local and staging sites run unlocked and never use a slot. That covers localhost, any .local or .test address, and hosts starting with staging., stage., dev. or test..
  • Moving to a new domain? Press Remove from this site on the old one first, which frees the slot. If you no longer have access to the old site, ask us and we will release it.
  • A ThemeForest purchase code covers one site.

If the license server is unreachable

The last successful check is trusted for seven days. A network problem or an outage on our side will not switch your site's modules off.

Header & Footer Builder Free

Replace the theme's header and footer with layouts you build in Elementor.

  1. Go to Vantorix → Header & Footer Builder and press Add New.
  2. Name it, choose Header or Footer, and set where it should appear.
  3. Press Create and edit to open Elementor.
  4. Build, publish, and it replaces the theme's own.

If two templates could apply to the same page, the one with the higher priority number wins.

Popup Builder Free

Design popups in Elementor and choose what opens them.

  • Triggers — on page load, after a delay, at a scroll depth, on exit intent, or on a click.
  • Frequency — once per visitor, once per session, or every time. Cookie length is yours to set.
  • Audience — logged in, logged out, or specific roles.
  • Devices — show or hide per breakpoint.

404 Page Builder Free

Build the page people land on when a URL does not exist. You can also redirect certain missing URLs somewhere useful, and keep a log of what people are failing to find — that log is often the fastest way to spot a broken link on your own site.

Screen Loader Free

A loading screen shown while the page prepares. Pick an animation, a timeout, and whether it appears on every visit or only the first. Keep the timeout short — a loader that outstays the page is worse than no loader.

Archive Builder Pro

Design the pages that list posts: blog index, category, tag, author, date and custom post type archives.

  1. Go to Vantorix → Archive Builder → Add New.
  2. Build the layout with the Post Block or Post List widget as the loop.
  3. Open Display Conditions and choose which archives it applies to.
  4. Preview against a real archive while you work.

One template can cover every archive, or you can make a separate one per post type. Use the exclude rules when a template should apply everywhere except one place.

Single Post Builder Pro

Lay out single posts, pages and custom post types. The same targeting rules apply, plus exclusions and a priority order.

Build with the dynamic widgets — Post Title, Post Content, Featured Image, Post Meta, Post Terms, Post Comments — so one template serves every post.

Search Builder Pro

Replace the theme's search results page. While editing you can set a preview term so you are designing against real results rather than an empty screen. Remember to design the empty state too — it is the screen people see most often when a search goes wrong.

Dynamic Tags Pro

Dynamic tags pull real content into any Elementor field. Look for the small database icon next to a control, then pick a tag.

Post

Title, excerpt, content, ID, URL, date, modified date, featured image, comment count.

Author

Name, bio, profile picture, posts URL, website, email.

Site

Title, tagline, URL, logo, current date, current year, user name.

Archive

Title, description, term name, term URL, post type name.

Fields

Custom fields, ACF text, image, number, date, relationship and repeater values.

Media

Featured image URL, attachment title, caption and alt text.

Template Library Pro

Ready-made layouts you can import in one click, and a place to save your own for reuse.

  • Templates — individual headers, footers, archives and single layouts.
  • Kits — a matched set plus its global colours and fonts.
  • Your layouts — save any template you build and drop it into the next project.

Importing a kit overwrites the site's global colours and fonts. Try it on a staging copy before running it on a site that is already live.

Display conditions

Every builder template uses the same targeting panel, so once you learn it in the Header Builder you know it everywhere.

SettingWhat it does
IncludeWhere the template should appear. Add several rules to cover several places.
ExcludeCarve out exceptions from the include rules.
User rolesLimit the template to specific logged-in roles.
PriorityWhen more than one template matches, the higher number wins.

Rules read from broad to narrow: Entire site, then a post type, then a single page. A narrower rule does not automatically beat a broader one — set the priority when you need a specific outcome.

Widgets

All widgets are in the free plugin and appear under the Vantorix category in the Elementor panel.

Posts

Post Block, Post List, Post Title, Post Content, Post Excerpt, Post Meta, Post Terms, Post Comments, Featured Image.

Navigation

Nav Menu, Breadcrumb, Search, Search Results, Categories, Tag Cloud, Back to Top.

Content

Advanced Heading, Advanced Image, Feature Cards, Gallery, Brand, Testimonial, Progress, Marquee.

Interaction

Accordion, Toggle, Smart Contact Actions, Sticky Element.

Turn off the ones you do not use under Vantorix → Widgets. Disabled widgets load no CSS or JavaScript at all, which is the simplest performance win available to you.

Hooks for developers

The free plugin exposes these so add-ons and child themes can extend it.

// Fires after the free modules have booted.
do_action( 'vantorix_modules_loaded' );

// Register your own Elementor dynamic tags.
do_action( 'vantorix_register_dynamic_tags', $dynamic_tags_manager );

// Tell the plugin a licensed Pro add-on is present.
apply_filters( 'vantorix_pro_active', false );

Pro adds two more, useful while testing:

// Point the license client at a different API.
apply_filters( 'vantorix_pro_api_url', $url );

// Treat this install as a development site.
apply_filters( 'vantorix_pro_is_development_site', $is_dev, $host );

Troubleshooting

“cURL error 60: SSL certificate…” on the License screen

Your server cannot verify our certificate. This is almost always a local install missing an up-to-date certificate bundle rather than a problem with the license. Local sites run unlocked anyway, so you can carry on. On a live site, ask your host to update the server's CA certificates.

To silence it on a local install, add this to wp-config.php:

define( 'WP_ENVIRONMENT_TYPE', 'local' );

My header or footer does not show

  • Check the template is published, not a draft.
  • Check its display conditions actually include the page you are looking at.
  • Some themes render their own header regardless. Try a theme like Hello Elementor to confirm.

Pro modules are missing after activating Pro

  • Check Vantorix → License shows Active.
  • Check the free plugin is version 1.1.0 or newer.
  • Switch the modules on under Vantorix → Modules — they do not enable themselves.

Styles look wrong after an update

Regenerate Elementor's files under Elementor → Tools → Regenerate CSS & Data, then clear any caching plugin and your CDN.

Questions

Is the free plugin limited?

No. It contains no locked code. Pro is a separate plugin that adds modules on top — nothing in the free plugin is switched off to sell you something.

Does Pro renew?

You pay once. Updates are included for the period listed on your package. The plugin keeps working after that; you just stop receiving new versions until you renew.

What if I stop paying?

Your site keeps running. Templates you built stay where they are.

Can I use it on client sites?

Yes. Each client site uses one slot from your license. The Agency package exists for this.

Is there a refund?

Tell us within 14 days if it does not work for you and we will refund it. We would rather hear what went wrong than keep the money.

Do you offer support in Bengali?

Yes — WhatsApp or Facebook, whichever you prefer.

Still stuck?

Send us the site URL and what you were doing, and we will look at it.
